# 제50조 (행정적책임)

다음의 경우에는 기관, 기업소, 단체의 책임 있는 일군과 개별적 공민에게 정상에 따라 해당한 행정처벌을 준다.

1. 건설질서를 어기고 상수도시설을 건설하여 썩나 건설물의 질을 보장하지 못하였을 경우

2. 승인 없이 사용 중에 있는 상수도관에 인입관을 련결하였을 경우

3. 생황욜수를 계획대로 생산, 공급하지 못하였을 경우

4. 상수도시설을 파손시켰거나 승인 없이 페기, 용도변경하여 생활용수의 생산, 공급에 지장을 주었을 경우

5. 상수도시설관리와 운영에 필요한 보장사업을 제대로 하지 않아 생활용수의 생산, 공급에 지장을 주었을 경우

6. 생활용수의 수질기준을 보장하지 못하였을 경우

7. 제27조에 규정된 행위를 하였을 경우

8. 송수관, 배수관, 급수관이 설치된 일정한 구간 안에 건물, 시설물을 건설하거나 나무를 심어 그 관리에 지장을 주었을 경우

9. 승인 없이 생활용수를 공업용수로 리용하였을 경우
