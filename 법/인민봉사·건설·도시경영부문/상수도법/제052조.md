# 제52조 (경고, 엄중경고, 무보수로동, 로동교양, 강직, 해임, 철직처벌)

다음의 경우에는 책임 있는 자에게 경고, 엄중경고 또는 3개월 이하의 무보수 로동, 로동교양처 벌을 준다.

1. 건설질서를 어기고 상수도시설을 건설하였거나 건설물의 질을 보장하지 못하였을 경우

2. 승인 없이 사용 중에 있는 상수도관에 인입관을 련결하였을 경우

3. 생활용수를 계획대로 생산, 공급하지 못하였을 경우

4. 상수도시설을 파손시켰거나 승인 없이 페기, 용도변경하여 생활용수의 생산, 공급에 지장을 주었을 경우

5. 상수도시설관리와 운영에 필요한 보장사업을 제대로 하지 않아 생활용수의 생산, 공급에 지장을 주었을 경우

6. 생활용수의 수질기준을 보장하지 못하였을 경우

7. 위생보호구역 안에서의 금지사항을 어겼을 경우

앞항의 행위를 여러번 하였거나 2만원분 이상의 재산적 손실을 가져오게 하였을 경우 3개월 이상의 무보수로동, 로동교양처벌 또는 강직, 해임, 철직처벌을 준다.
