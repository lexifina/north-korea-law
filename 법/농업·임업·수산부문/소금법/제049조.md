# 제49조 (벌금)

다음의 경우에는 해당 기관, 기업소, 단체에 벌금을 물린다.

1. 소금밭과 생산설비에 대한 보수, 기술관리를 바로 하지 않아 생산성과 효률을 떨어뜨렸을 경우 30만~100만원

2. 로동보호사업을 무책임하게 하여 사고를 일으켰을 경우 30만~150만원

3. 소금생산에서 정해진 품질을 보장하지 못하였을 경우 20만~150만원

4. 소금의 수송, 보관을 무책임하게 하여 류실시켰을 경우 10만~150만원

5. 공급받은 소금을 다른 용도에 리용하였을 경우 20만~150만원

6. 소금소비기준을 어겼을 경우 10만~100만원
