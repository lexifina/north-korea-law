# 제45조 (중소탄광개발승인의 취소 사유)

다음의 경우에는 중소탄광개발승인을 취소한다.

1. 중소탄광개발신청을 허위로 하였을 경우

2. 중소탄광개발이 승인된 날부터 3개월 안에 중소탄광개발승인등록을 하지 않았거나 6개월 안으로 개발에 착수하지 않았을 경우

3. 중소탄광개발을 6개월 이상 중지하였을 경우

4. 승인 없이 중소탄광개발권을 다른 기관, 기업소, 단체에 넘겨주었을 경우

5. 비법적으로 다른 기관, 기업소, 단체와 합동하여 중소탄광을 개발하였을 경우

6. 승인된 개발구역을 벗어나 석탄을 채굴할 경우

7. 중앙공업탄광의 갱을 임대하여 석탄을 생산하거나 다른 단위에 갱을 임대하였을 경우
