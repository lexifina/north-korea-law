# 제27조 (하천리용을 승인하였을 경우)

하천의 리용을 승인받은 경우는 다음과 같다.

1. 하천의 물을 생활용수, 공업용수, 관개용수로 리용하려 할 경우

2. 하천수역토지를 농경지 또는 부업지로 리용하려 할 경우

3. 하천수역에 언제, 저수지, 발전소, 부두, 양어장, 물놀이장, 다리 같은 것을 건설하거나 변경, 페기하려 할 경우

4. 하천수역에서 사금, 모래, 자갈, 흙 같은 것을 채취하려 할 경우

5. 하천의 물줄기를 변경시키려 할 경우

6. 배를 항행시키거나 떼목을 나르려 할 경우

7. 하천의 주변에 심은 나무를 베거나 수종을 바꾸려 할 경우
